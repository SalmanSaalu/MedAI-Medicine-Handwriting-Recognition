# MedScript AI

MedScript AI is a research prototype for recognizing handwritten medicine names with a fine-tuned TrOCR model. Model training, dataset splitting, and validation are intended to run in Google Colab with a GPU. The local Streamlit app is for inference and manual review.

> **Safety:** OCR can produce plausible but incorrect medicine names. This prototype is not a clinical decision system. A qualified healthcare professional must verify every result against the original prescription.

## Project contents

- `app.py` — Streamlit interface for uploading handwriting, viewing candidate text regions, and reviewing OCR.
- `train_trocr.py` — GPU fine-tuning; saves the selected checkpoint to `models/trocr-medicine`.
- `split_dataset.py` — validates the annotated images, removes exact-image duplicates, and creates train/validation/test CSVs.
- `evaluate_trocr.py` — calculates CER and exact-match accuracy and writes per-image predictions.
- `data/RxHandBD/` — annotations and word images included in the Colab training archive.
- `data/splits/` — original partition manifests and generated split CSVs.
- `models/trocr-medicine/` — trained model and processor files; generated by training.

## Train and validate in Google Colab

1. Upload `MedScript_Colab_Training_fixed.zip` to the root of your Google Drive.
2. Select a GPU runtime in Colab.
3. Run the following cells in order. Training can take a long time; wait for each command to finish before continuing.

```python
from google.colab import drive
from pathlib import Path
from zipfile import ZipFile

drive.mount("/content/drive")

zip_path = Path("/content/drive/MyDrive/MedScript_Colab_Training_fixed.zip")
if not zip_path.is_file():
    raise FileNotFoundError(f"Upload the training ZIP to Drive: {zip_path}")

with ZipFile(zip_path) as archive:
    archive.extractall("/content")

%cd /content/MedScript-Colab
%pip install -r requirements-colab.txt
```

Confirm that Colab has a GPU, then create the splits and train:

```python
import torch

if not torch.cuda.is_available():
    raise RuntimeError("Enable a GPU runtime in Colab, then rerun this cell.")

print("GPU:", torch.cuda.get_device_name(0))

import subprocess
import sys

subprocess.run([sys.executable, "split_dataset.py"], check=True)
subprocess.run([sys.executable, "train_trocr.py"], check=True)
```

Evaluate the trained model on the validation split. Use validation results for model or decoding choices; keep the test split untouched until final evaluation.

```python
subprocess.run([
    sys.executable,
    "evaluate_trocr.py",
    "--csv", "data/splits/validation.csv",
    "--output", "validation_predictions.csv",
    "--num-beams", "3",
], check=True)
```

The split step validates the annotations and image files, applies the supplied partition manifests, and resolves exact byte-identical images to prevent leakage. Same-label duplicates are retained in only one split; identical images with conflicting labels are excluded for manual review. Decisions are recorded in `data/splits/duplicate_resolution.csv`. If the split script fails, fix the reported issue before training.

Save the model and run outputs to Drive. The timestamped folder keeps each run's model, split files, metrics, and validation predictions together:

```python
from datetime import datetime
from pathlib import Path
from zoneinfo import ZoneInfo
import shutil

model_source = Path("models/trocr-medicine")
if not (model_source / "model.safetensors").is_file():
    raise FileNotFoundError("The trained model file was not found.")

run_name = datetime.now(ZoneInfo("Asia/Kolkata")).strftime("run_%Y%m%d_%H%M")
save_dir = Path("/content/drive/MyDrive/MedScript-Training-Results") / run_name
save_dir.mkdir(parents=True, exist_ok=True)

shutil.copytree(model_source, save_dir / "trocr-medicine", dirs_exist_ok=True)
shutil.copytree("data/splits", save_dir / "splits", dirs_exist_ok=True)

for filename in ("training_metrics.csv", "validation_predictions.csv"):
    source = Path(filename)
    if source.is_file():
        shutil.copy2(source, save_dir / filename)

print("Saved model and results to:", save_dir)
```

For a final held-out evaluation, run:

```python
subprocess.run([
    sys.executable,
    "evaluate_trocr.py",
    "--csv", "data/splits/test.csv",
    "--output", "test_predictions.csv",
    "--num-beams", "3",
], check=True)
```

Do not use test results to tune the model. Copy the complete `trocr-medicine` folder from Drive into this project's `models/trocr-medicine` directory for local inference.

## Run the local app

Use Python 3.11 or 3.12. From the project root on Windows:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
streamlit run app.py
```

The first run may download `microsoft/trocr-base-handwritten` if a fine-tuned model is not present. For best recognition, copy the complete trained model and processor folder to `models/trocr-medicine`. The app's candidate-region detection is heuristic and may miss or incorrectly group handwriting; inspect each crop and edit each prediction before use.

## Dataset format

The annotations CSV uses these columns:

```csv
image_path,text
data/RxHandBD/Train_Set/P2509.jpg,Calbo-D
```

Relative image paths are resolved from the project root. The current annotations do not include writer or prescription IDs, so the supplied partitioning cannot guarantee writer-independent evaluation.
